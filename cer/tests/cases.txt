# CEr unit cases: plain JavaScript, run by tests/cases.rs in a fresh
# engine each. The expected value is what Node answers (the value of the
# script's last expression statement); CErXes runs the same cases
# (its tests/syntax.rs) and must answer the same.
#
# A case: `==== js <title>`, the script, `----`, the value.
