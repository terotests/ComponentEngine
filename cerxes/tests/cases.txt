# CErXes syntax cases, run by tests/syntax.rs (cargo test) and by
# bench/cases.mjs on the Ranger build (rgrc src/lib.rs, JavaScript).
#
# A case: a line `==== <syntax>` (tsx, ts, jsx or js), the script, a line
# `----`, and the value the script answers (its last expression statement,
# or its error). Lines starting with `#` before a case are comments.
