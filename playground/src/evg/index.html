CErXes + EVG: a game loop in TSX

The script in the TSX tab is TypeScript with JSX, run by CErXes (CEr with a TypeScript and JSX front-end) compiled to WebAssembly. Every frame its view() returns JSX; the element tree is styled by the CSS tab, laid out and flattened to draw commands by EVG (a CSS-shaped layout engine written in Ranger, compiled to JavaScript), and painted as SVG. The browser lays nothing out.

How a frame is made
  1. The page sends the input (keys held, the pointer, clicks since the last frame, each with the id of the element EVG's hit test found under it) to a Worker running CErXes.
  2. CErXes calls the click handlers, then tick(dt, input), then view(), and returns the element tree as JSON. Functions passed as onClick stay in the engine under an id.
  3. The page makes the tree into EVG elements (class names, ids, inline style); EVG applies the stylesheet, lays the tree out at 640×480 and builds its display list.
  4. EVG's SVG painter draws the list. Text is measured by the browser's canvas and broken into lines by EVG.

Keyboard: click the game first. The script can define onKeyDown(key) and onKeyUp(key); input.keys holds the keys down, input.pointer the pointer.

EVG's CSS subset: class selectors (.a, .theme .a, :hover), the box model, flex, grid, position: absolute, colours, radii, borders, fonts, @media and custom properties.
