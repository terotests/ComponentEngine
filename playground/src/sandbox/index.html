CErXes sandboxes: four computations that never end

Each card is a CErXes engine (WebAssembly) running its own program, a fractal drawn in passes that get finer and deeper forever. The interpreter stops by itself when its time slice runs out, at any branch, call or return, even inside while (true), and goes on from there at the next turn. So four endless programs share the page's own thread and the page stays responsive. The same engines can also run in Web Workers (their own threads) or in iframes (their own documents, the page's thread).

Click a picture to zoom in there, or scroll over it, or use its + / − buttons; drag it to pan (Shift-click or right-click zooms out). Freeze writes the engine's whole state, the running loop included, as text; Thaw makes a new engine from it. Changing a card's host moves the running program that way: frozen in one place, thawed in another.
